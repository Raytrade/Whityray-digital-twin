🔐 Safety gates before money goes live

  • Server-side authentication and founder-role authorization.
  • Secrets held only in server environment variables—never browser code or GitHub.
  • Provider-confirmed deposits, withdrawals and explicit transaction states.
  • Unique idempotency references, ledger reconciliation and audit logs.
  • Per-transfer limit, daily limits, withdrawal approval and fraud checks.
  • Test-mode end-to-end tests before any live transaction is enabled.
